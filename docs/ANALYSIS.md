# 분석 설계와 한계

TF-IDF와 K-means는 단어 동시 출현 패턴을 묶을 뿐 버그·밸런스 같은 의미를 자동 이해하지 않습니다.
군집의 `issue_type`은 상위 키워드와 공개된 규칙표로 붙인 참고 라벨입니다. 실제 우선순위는 군집별
개수가 아니라 리뷰별 다중 이슈 분류를 집계하므로 한 리뷰가 버그와 성능 양쪽에 포함될 수 있습니다.

VADER compound는 영어 감성 휴리스틱입니다. 반어법, 부정 범위, 게임 은어, 업데이트 전후 맥락을
오판할 수 있습니다. Steam 추천 여부(`voted_up`/기존 `sentiment`)와 텍스트 감성은 독립 지표로
유지합니다. 대표 리뷰와 원문을 사람이 확인해야 합니다.

Silhouette score는 군집 분리 정도의 보조 지표이지 의미 품질 보증이 아닙니다. 리뷰가 k보다 적으면
명시적으로 실패하며, 서로 동일한 리뷰 때문에 실제 군집 수가 부족한 경우 경고합니다. 데이터가
10,000건 이상이면 MiniBatchKMeans를 사용하고 silhouette은 최대 2,000건 표본으로 계산합니다.

현재 이슈 사전은 초기 영어 키워드 규칙입니다. 실제 Steam 데이터에서 오탐·미탐을 표본 검수한 뒤
게임 도메인 용어와 활용형을 추가해야 합니다. 사전 변경 시 테스트 데이터와 결과 버전을 함께 기록할
것을 권장합니다.
